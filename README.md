# CreatorOS Vision

You are designing the complete high-fidelity frontend UI/UX prototype for a product called:

CREATOROS AI

CreatorOS AI is a premium AI-powered Creative Operating System for creators, freelancers, and digital professionals.

IMPORTANT:

This task is primarily a FRONTEND DESIGN + UI/UX task.

Build the entire frontend experience as a polished, production-quality visual prototype.

Do NOT build or depend on a real backend, database, Prisma, Neon, Better Auth, API integrations, or AI model integrations.

Use realistic mock/placeholder data only where appropriate for visual demonstration, but clearly distinguish future/unimplemented functionality from real functionality.

The goal is to produce a frontend that looks like a real premium product ready for production integration.

- links

- focus states

Semantic colors:

- green = success

- amber = warning

- subtle branding
